# Todo-List
This is a simple Todo-List application built using HTML, CSS and JavaScript as part of The Odin Project Curriculum. It allows users to create project folders within which their todo tasks will reside.

# Features
- Creating a new project folder.
- Creating tasks under the same folder.
- Color coding for the various tasks depending on their priority.
- Marking tasks as complete by checking the complete checkbox.
- Automatic completion of tasks when all check items have been checked.
- Deletion of project folders with the exception of the default  as well as tasks within.
- Ability to rename project folders.
- Persisting data in the user's local storage and retrieving them as needed.

# Tools Used
